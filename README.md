# 食べ歩きメモ 🍜

行きたい・行った飲食店を、写真つきで記録するシンプルなメモアプリ。
**ログイン不要**・データは端末内に保存（PWA）。

## 特徴
- 店を追加（店名 / 都道府県 / 食べログ等のURL / メモ）
- 「行きたい」⇄「行った」をワンタップ切替
- 店ごとに写真を保存（取り込み時に自動で軽く圧縮・最大10枚）
- 都道府県 × 状態でしぼり込み
- バックアップの書き出し / 読み込み（機種変・データ消え対策）
- ホーム画面に追加でアプリのように使える（オフライン対応）

## 技術
素の HTML / CSS / JavaScript + IndexedDB。ビルド不要の静的サイト。

## 使い方（ローカル）
```bash
python -m http.server 5510
```
ブラウザで `http://localhost:5510` を開く。

## データについて
すべてブラウザ内（IndexedDB）に保存され、サーバーには送信されません。
端末やブラウザのデータを消すと失われるため、こまめに「バックアップを書き出す」で退避してください。
